# Farmer sleeping animation: sprite sheet brief

For the project owner to generate with OpenAI's image generation tool. Nothing here has been generated yet. Decision D43 (breathing only, the farmer stays asleep) applies to the first row. The second row is optional and is not approved for use until the owner says so.

## What to attach to the tool

1. `docs/references/animation/farmer-reference-on-magenta.png` (the exact character on flat magenta)
2. `docs/references/retro-room-reference.png` (the approved scene, style only)

## Frames needed (8 frames, 4 columns x 2 rows)

| Cell | Frame | What changes |
| --- | --- | --- |
| Row 1, col 1 | B1 rest | Exactly the reference pose |
| Row 1, col 2 | B2 inhale | Chest and belly rise slightly, the hand resting on the chest and the orange neckerchief rise with them |
| Row 1, col 3 | B3 inhale peak | Chest at its highest (about 2 to 3 pixels of the original sprite higher than rest) |
| Row 1, col 4 | B4 exhale | Chest lowering, between B3 and B1 |
| Row 2, col 1 | S1 rest | Same as B1 |
| Row 2, col 2 | S2 stir | Eyes crack open to a thin dark slit, still sleepy |
| Row 2, col 3 | S3 settle | Eyes closed again, eyebrows very slightly raised |
| Row 2, col 4 | S4 rest | Same as B1, so the loop closes |

## Prompt (paste with the two attached images)

```
Use the first attached image as the exact character reference: the same sleeping farmer lying on
his back on the ground, the same blue cap with the brown tuft, the same face with closed eyes, the
same cream shirt with the orange neckerchief, the same blue overalls and dark brown boots, the same
proportions, colors, chunky visible pixels, soft dithered shading and thin dark-brown edge shading,
the same camera and light from the top left. Use the second image only as a style reference.
This is an original character: do not copy or imitate any existing video game character or sprite.

Create ONE sprite sheet image, 1536 x 1024 pixels, with 8 equally sized cells in 4 columns and
2 rows (each cell 384 x 512 pixels). The background of the whole image is one flat solid color,
exactly #FF00FF (pure magenta): no gradient, no noise, no ground, no grass, no cast shadow, no text,
no numbers, no labels, no grid lines, no borders.

Draw the same farmer, in the same position and orientation as the reference, in every cell. Keep
the head, cap, legs and boots in exactly the same place and shape in all 8 cells: only the parts
named below may change. Center the farmer in its cell, keep the same size in every cell (within
3%), put the lowest point of the boots and body on the same baseline in every cell, and keep at
least 40 pixels of empty magenta between the farmer and every cell edge.

Row 1, a breathing cycle, left to right (only the chest, belly, resting hand and neckerchief move):
1. Rest, exactly like the reference.
2. Inhale: chest and belly rise slightly, the hand and the neckerchief rise with them.
3. Inhale peak: chest at its highest, about 2 to 3 pixels of the original sprite above rest.
4. Exhale: chest lowering, between frame 3 and frame 1.

Row 2, a light stir (only the eyes and eyebrows change):
1. Rest, same as row 1 frame 1.
2. Eyes crack open to a thin dark slit, still sleepy.
3. Eyes closed again, eyebrows very slightly raised.
4. Rest, same as row 1 frame 1.

Style rules: hard pixel edges with no anti-aliased blur or glow, a limited palette close to the
reference, no pink or magenta tones on the farmer, no motion lines, no "Z" letters or speech
bubbles, no other objects, animals or people. Each frame must show a real change in the named
parts, not a moved, rotated or scaled copy of one drawing.
```

## If the result is poor

- Ask for "the same character as the attached image, only the named parts change" and regenerate.
- Frames where the head, cap or boots move between cells are the usual failure. Regenerate the sheet or ask for the single bad cell with the best sheet attached.
- If row 2 looks wrong, row 1 alone is enough for breathing.

## Acceptance checklist

- 8 frames in the layout above, one farmer each
- Head, cap, legs and boots identical in position across frames; only the named parts change
- Same size within about 3%; lowest point on one baseline; nothing touches a cell edge
- Flat magenta background, no magenta or pink on the farmer, no text, shadows, grid lines or "Z"
- Row 1 reads as slow breathing; row 2 (if used) reads as a faint stir
- The owner has checked that the farmer does not look like a Harvest Moon sprite
